# 💰 Personal Finance Tracker

A simple **Personal Finance Tracker** built with Python to record and summarize personal expenses.

This is my first Python project, created as part of my journey of learning **Python, Object-Oriented Programming (OOP), file handling, data structures, and basic data**

## 📌 Features

* 💵 Add new expenses
* 🏷️ Categorize expenses
* 💾 Save expenses to a CSV file
* 📊 View expenses grouped by category
* 🧮 Calculate total spending
* 💰 Calculate remaining budget
* 📅 Calculate the recommended daily budget based on the remaining days of the month
* ⚠️ Input validation for expense amounts and categories

## 🛠️ Technologies Used

* **Python**
* **Object-Oriented Programming (OOP)**

## 📂 Project Structure

```text
Personal-Finance-Tracker/
│
├── expense.py
├── expense_tracker.py
├── expense.csv
├── README.md
├── LICENSE
└── .gitignore
```

### `expense.py`

Contains the `Expense` class, which is used to represent individual expenses.

### `expense_tracker.py`

Contains the main application logic, including:

* Taking expense input
* Validating user input
* Saving expenses
* Reading saved expenses
* Summarizing expenses
* Calculating budget information

### `expense.csv`

Stores the recorded expense data.
